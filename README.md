This repository contains a video-swiping application that was built for CS 460, Software Engineering for Mobile Devices,  
at Central Washington University. Its primary language is Java, and it was developed in Android Studio (API level 26).  

All videos were sourced from Pixabay, an open-source media platform. You may find their files at  
https://github.com/EthanRocklin/open-source-footage or at the artists' Pixabay pages:  

baby-dancing.mp4          Pixabay : patw64  
christmas-ornament.mp4    Pixabay : xBriantcx  
dubai.mp4                 Pixabay : engrahmad2653  
magma.mp4                 Pixabay : Gylfi  
ski-lift.mov              Pixabay : spinheike  
steve-dancing.mp4         Pixabay : Exceptional_3D  
temple.mp4                Pixabay : mostafa_meraji  
van-life.mp4              Pixabay : Marsel_beijing  

Videos load automatically and are in swipe format. Swipe up to go to the next video, or swipe down to go  
to the previous video. Each video has a mock title, description, and identification number. See the following  
demo images:
